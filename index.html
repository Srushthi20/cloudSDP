Project

Database · Full-stack

CINSIC

A comprehensive entertainment database that connects movies, music, artists, awards and streaming platforms in one schema, so questions that span all of them can be answered with a single query.

The frontend is inspired by Netflix and Spotify and includes a live SQL Query Lab, where queries run against the database from the browser. The project follows a scalable three-tier architecture.
